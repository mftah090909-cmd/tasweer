## نبذة عن المشروع / Overview

**LUMIX PRO** هو تطبيق كاميرا احترافي حقيقي لنظام **أندرويد** مبني بـ **Kotlin** و **Jetpack Compose** مع **CameraX** و **Camera2 API** ومكتبات **Media3**. يهدف التطبيق إلى استخراج أقصى جودة ممكنة من عتاد الكاميرا الفعلي للجهاز دون محاكاة أو واجهات وهمية.

> **LUMIX PRO** is a production-quality Android camera application built with **Kotlin**, **Jetpack Compose**, **CameraX**, **Camera2 API**, and **Media3**. It extracts the maximum possible quality from your phone's real camera hardware — every slider, mode, and toggle is wired to genuine device capabilities and image-processing algorithms.

## المميزات الرئيسية / Key Features

### 1. محرك الكاميرا الأساسي (Core Camera Engine)
- اكتشاف تلقائي لقدرات العتاد (الكاميرا الرئيسية، العريضة جدًا، المقرّبة، الماكرو، الأمامية).
- تبديل العدسات وتبديل الكاميرا الخلفية/الأمامية مع حفظ حالة الإعدادات.
- تحكم يدوي كامل (ISO، سرعة الغالق، التعريض EV، توازن البياض AWB، المسافة البؤرية للتركيز اليدوي MF).
- قفل التعريض AE-L وقفل توازن البياض AWB-L.
- تركيز بلمسة الإصبع مع حلقة تركيز متحركة ومنزلق تعريض مدمج.
- مؤقت تصوير (3ث / 5ث / 10ث) مع عدّ تنازلي على الشاشة.
- لقطات متتابعة (Burst) بالضغطة الطويلة أو بوضع الرياضة.
- خطوط تكوين متعددة: قاعدة الأثلاث 3×3، النسبة الذهبية φ، الأقطار، ودليل مسح المستندات.
- ميزان أفق رقمي بدرجات الميل الحقيقية ومؤشر أخضر عند الاستواء.
- مخطط إضاءة حي (Histogram) بـ 256 نطاقًا.
- تحديد بؤرة التركيز (Focus Peaking) بألوان ساطعة على الحواف الحادة.
- تحذير التعريض الزائد (Zebra Stripes) على المناطق الساطعة.
- دعم التقاط RAW/DNG عند توفره في العتاد.

### 2. محرك تحسين الصور بالذكاء الاصطناعي (AI Enhancement Engine)
خوارزميات معالجة حقيقية غير وهمية تشمل:
- **دقة فائقة (Super-Resolution)** بإعادة بناء التفاصيل عالية التردد.
- **تقليل تشويش متقدم (Bilateral Filter)** يحافظ على الحواف.
- **تعزيز الإضاءة المنخفضة** بمعادلة التباين التكيفية المحلية (CLAHE-style).
- **حدة ذكية** بقناع إلغاء الحدة ومقاومة الهالات (Halo Control).
- **حفظ تفاصيل البشرة وملمسها الطبيعي** بالفصل الترددي للطبقات.
- **استعادة الإضاءات والظلال** وتوسيع المدى الديناميكي.
- **تصحيح توازن البياض التلقائي** بخوارزمية Gray-World.
- **إزالة التغبيش (Wiener Deblur)**.
- **تصحيح تشوه العدسة** (Barrel / Pincushion).

**المستويات الخمسة للتحسين:**
1. **طبيعي (Natural)** — لمسة هادئة تحفظ المشهد كما هو.
2. **احترافي (Professional)** — توازن مثالي بين المدى الديناميكي ونقاء البشرة.
3. **فائق التفاصيل (Ultra Detail)** — إعادة بناء التفاصيل الدقيقة والتباين المجهري.
4. **أقصى ذكاء اصطناعي (AI Maximum)** — السلسلة الكاملة بدقة عالية ومعالجة ليلية.
5. **سينمائي (Cinematic)** — ألوان سينمائية وظلال دافئة مع تلاشي إضاءة ناعم.

### 3. أوضاع التصوير الـ 17 (17 Professional Modes)
`AUTO` · `PRO` · `PORTRAIT` · `NIGHT` · `HDR` · `MACRO` · `LANDSCAPE` · `STREET` · `SPORTS` · `FOOD` · `ARCHITECTURE` · `LONG EXPOSURE` · `PANORAMA` · `TIME-LAPSE` · `DOCUMENT` · `HIGH-RES` · `RAW`

- **HDR**: دمج تعريضات متعددة (EV -2, 0, +2) بخوارزمية Mertens للوزن المثالي.
- **Night**: دمج لقطات متعددة لتقليل التشويش الليلي.
- **Long Exposure**: محاكاة التعريض الطويل للشلالات ومسارات الضوء مع خيار المدة (1-10 ثوانٍ).
- **Panorama**: دمج صور متتابعة مع تدرج حواف ناعم.
- **Time-lapse**: التقاط بفواصل زمنية مخصصة (1-30 ثانية).
- **Document Scanner**: عتبة تكيفية وتعزيز التباين للمستندات واللوحات.

### 4. كاميرا الفيديو الاحترافية (Professional Video)
- تسجيل حتى 4K UHD / 1080p FHD / 720p HD / 480p SD حسب دعم الجهاز.
- 24 / 30 / 60 إطار في الثانية (و 120 fps للحركة البطيئة عند توفره).
- تثبيت فيديو إلكتروني وبصري (EIS / OIS).
- مقياس حقيقي لمستوى الصوت (VU Meter) عبر الميكروفون في الوقت الفعلي.
- مؤقت تسجيل وتقدير الدقائق المتبقية حسب المساحة المتاحة.
- إيقاف مؤقت واستئناف.

### 5. محرك تحسين الفيديو (AI Video Enhancement)
معالجة غير متزامنة (Offline) لما بعد التسجيل بـ Media3 Transformer:
- رفع الإضاءة المنخفضة مع كبح التشويش.
- تلوين سينمائي وتدرج حرارة الألوان.
- رفع/تخفيض الدقة وجودة التصدير.
- شريط تقدم فعلي وإمكانية الإلغاء.

### 6. المحرر الاحترافي المدمج (Built-in Editor)
**محرر الصور:**
- الإضاءة: التعريض، التباين، الإضاءات، الظلال، البيض، السود.
- اللون: الحرارة، الصبغة، النضارة (Vibrance)، التشبع.
- التفاصيل: الوضوح (Clarity)، الملمس (Texture)، الحدة، تقليل التشويش.
- المؤثرات: التعتيم الطرفي (Vignette)، حبيبات الفيلم (Film Grain).
- فلاتر سينمائية (LUT): تيل وأورانج، فيلم كلاسيكي، أبيض وأسود، غروب دافئ، بارد درامي، غابات، تألق البورتريه، سايبربانك، والمزيد.
- HSL بثمانية نطاقات لونية (الأحمر .. الماجنتا).
- منحنى نغمة مخصص، التدوير 90°، وقص بنسب شائعة (1:1، 4:3، 16:9، 9:16، حر).
- مقارنة منقسمة تفاعلية بسحب المقبض (Split Before/After).
- حفظ نسخة جديدة دائمًا مع نقل كامل بيانات EXIF الأصلية.

**محرر الفيديو:**
- قص البداية والنهاية بشريط زمني.
- تدوير الفيديو (90°، 180°، 270°).
- سرعات متعددة (0.25×، 0.5×، 1×، 1.5×، 2×، 4×).
- قوالب تلوين سينمائية.
- كتم الصوت وتحديد دقة التصدير.

### 7. واجهة مستخدم Liquid Glass فاخرة
- خلفية جرافيت داكنة (#0A0C10) مع أسطح زجاجية شبه شفافة.
- زر غالق ثنائي الحلقات مع اهتزاز لمسي وحلقات تسجيل وتقدم.
- عجلة تقريب تفاعلية وشريط أوضاع انسيابي.
- شريط إعدادات سريعة وحركات انسيابية لكل لوحة.

### 8. المساعد الذكي للتصوير (AI Assistant)
- تصنيف المشهد في الوقت الفعلي (ليلي، إضاءة منخفضة، ساعة ذهبية، غروب، تعريض مفرط، إضاءة خلفية، اهتزاز، مستند).
- نصائح مخصصة لكل مشهد مع زر **"تطبيق" بنقرة واحدة** لضبط ISO والغالق والتعريض والمود المناسب.
- تحذيرات الاهتزاز والتعريض المفرط والإضاءة الضعيفة.

### 9. المعرض الذكي (Smart Gallery)
- تبويبات: الكل، صور، فيديو، RAW، المفضلة، ألبوم خاص.
- بحث فوري بالاسم أو التاريخ.
- مشغّل فيديو داخلي بمعيار ExoPlayer مع ملء الشاشة وتكبير باللمس.
- لوحة بيانات EXIF تفصيلية لكل صورة (الكاميرا، العدسة، فتحة العدسة، ISO، سرعة الغالق، إحداثيات GPS، المساحة).
- مشاركة وحذف آمنان مع تأكيد.
- ألبوم خاص محمي محليًا داخل مساحة التطبيق دون ظهور في المعارض العامة.

### 10. إضافات مميزة (Premium Extras)
- **حاسبة الساعة الذهبية والزرقاء**: أوقات شروق/غروب وساعة ذهبية دقيقة فلكيًا حسب إحداثيات GPS لليوم.
- **تشخيص مستشعرات الكاميرا**: فحص كل حساس (المستوى البرمجي، دقة التصوير والفيديو، نطاقات ISO، التثبيت، دعم RAW).
- **إدارة المساحة**: رسم دائري للمساحة وتقدير عدد الصور وساعات الفيديو المتبقية.
- **مراقبة حرارة الجهاز والبطارية**: تنبيه عند اختناق المعالج حراريًا (Thermal Throttling).
- **العلامة المائية القابلة للتخصيص**: نص مخصص + تاريخ + تفاصيل الكاميرا EXIF.
- **حفظ واسترجاع إعدادات Pro**: عدد غير محدود من الإعدادات المسبقة في قاعدة بيانات محلية (Room).

## طريقة البناء / Build Instructions

### البناء المحلي (Local Build)

```bash
# 1) استنساخ المستودع
git clone https://github.com/mftah090909-cmd/tasweer.git
cd tasweer

# 2) إنشاء ملف local.properties إن لزم (مضمّن تلقائيًا عند الحاجة)
echo "sdk.dir=$ANDROID_HOME" > local.properties

# 3) بناء نسخة Debug APK
./gradlew assembleDebug

# 4) تجد ملف APK الجاهز للتثبيت هنا:
# app/build/outputs/apk/debug/LUMIX-PRO-v1.0.2-debug.apk
```

### البناء في Android Studio
1. افتح Android Studio (2024.2+ Ladybug أو أحدث).
2. اختر **File > Open** وحدد مجلد `tasweer`.
3. انتظر حتى يكتمل مزامنة Gradle، ثم اضغط **Run ▶** لتشغيل التطبيق على الجهاز.

### البناء التلقائي عبر GitHub Actions
كل **Push** إلى فرع `main` يُطلق سير عمل تلقائي يبني **LUMIX-PRO-Debug-APK** ويرفعه كأثر (Artifact) قابل للتنزيل من صفحة Actions، وعند إنشاء Tag بصيغة `v1.0.2` يُنشأ Release تلقائي مع ملفات APK المرفقة.
